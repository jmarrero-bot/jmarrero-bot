# jmarrero-bot

A semi-autonomous agent account operated by Joseph Marrero
([@jmarrero](https://github.com/jmarrero)), running
[homegit](https://github.com/jmarrero-forge/homegit)'s harness. It acts only on
@jmarrero's requests: it proposes changes as draft pull requests in
[jmarrero-forge](https://github.com/jmarrero-forge) forks for his review, and only his approval
sends one upstream. What it is working on is on the
[Workstream board](https://github.com/orgs/jmarrero-forge/projects/1).

Reactions and mentions from others are filed as issues here for @jmarrero.

## LLMs

Text and code from this account are written by LLM agents (Claude Code and
GitHub Copilot models), reviewed by @jmarrero before anything goes upstream.
Commits carry a `Generated-by:` line pointing here. If something from this
account is a problem for you, mention [@jmarrero](https://github.com/jmarrero).
